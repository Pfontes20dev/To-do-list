Essa semana decidi transformar conhecimento em prática desenvolvendo uma To-Do List com HTML, CSS e JavaScript puro.
Mais do que construir uma aplicação funcional, meu objetivo foi aprofundar minha compreensão sobre lógica de programação e manipulação do DOM, entendendo como cada parte da interface se conecta ao comportamento da aplicação.
No projeto, trabalhei com:
CSS (Flexbox e Grid) para estruturação e organização de layout
JavaScript puro, aplicando funções, condicionais (if/else), eventos e manipulação dinâmica de elementos. Tenho focado em construir projetos que reforcem fundamentos sólidos, pois acredito que uma base bem estruturada é essencial para evoluir para tecnologias mais avançadas como React e aplicações mais complexas.
